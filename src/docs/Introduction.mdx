# Keel

A themeable design system for the web, built from the variables and components in the
[Keel Figma file](https://www.figma.com/design/8IEdts3bNiwKEwISZ9Md9D/Keel).

## Tokens

Every Figma variable is a CSS custom property. Names follow the Figma path, whose top folder
carries the `keel-` prefix: `keel-color/slate/950` → `--keel-color-slate-950`,
`keel-surface/accent` → `--keel-color-surface-accent`.

| Figma collection | Modes | CSS |
| --- | --- | --- |
| Primitives | Value | `:root` in `generated/primitives.css` |
| Spacing and Radius | Mode 1 | `:root` in `generated/spacing-and-radius.css` |
| Accent | Default, Indigo | one file per mode in `generated/themes/` |
| Typography | Mode 1 | `:root` in `generated/typography.css` |
| Interactive | Mode 1 | `:root` in `generated/interactive.css` (unitless: opacity 0–1, scale factors) |
| Motion | Mode 1 | `:root` in `generated/motion.css` (durations in ms) |

Aliases are kept as `var()` references, so a theme token points at a primitive just like in Figma.
**Components use accent, spacing, radius, typography, interactive and motion tokens. Of the primitives, only font
family and font weight, which have no semantic tokens yet.**

## Themes

Each mode of the Accent collection is a theme. A theme applies to everything under an element
with `data-theme="<mode>"` (usually `<html>`). Default is also applied to `:root`.
Use the paintbrush in the toolbar to switch themes in any story.

## Updating tokens from Figma

After changing variables in Figma, run **`/sync-tokens`** in Claude Code. It pulls every variable,
verifies the copy is exact, regenerates `src/tokens/generated/`, makes sure every token appears here
in Storybook, and lists what changed.

Two commands keep code and Storybook honest (`/sync-tokens` runs both):

- `npm run tokens:check` fails if the generated CSS is out of date, or if any token isn't shown on a
  Foundations page (see `src/docs/foundations/coverage.ts`).
- `npm run tokens:diff` lists variables added, removed or changed since the last commit.

A new mode in the Accent collection becomes a new theme automatically, including in the toolbar.
Never edit files in `src/tokens/generated/` by hand.

## Icons

Icons come from the **Icons** page in Figma (components named `Icon/<name>`) and are used with
`<Icon name="check" />`. They are square: `size` is `xsmall` (12px), `small` (16px, the default), `medium` (20px),
`large` (24px) or `custom` with any `customSize` from 12px up. They use
`--keel-color-icon-default` unless you pass a `color`. See **Foundations / Icons** for the full set.

After adding or changing icons in Figma, run **`/sync-icons`** in Claude Code. `npm run icons:check`
fails if `src/icons/generated/` is out of date. Never edit it by hand.

## Adding a component

Create `src/components/<Name>/` with `<Name>.tsx`, `<Name>.css` and `<Name>.stories.tsx`,
then export it from `src/index.ts`.
