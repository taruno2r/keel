# ds-theming

A themeable design system for the web, built from the variables and components in the
[DS-Theming Figma file](https://www.figma.com/design/8IEdts3bNiwKEwISZ9Md9D/DS-Theming).

## Tokens

Every Figma variable is a CSS custom property prefixed `--ds-`. Names follow the Figma path:
`Color/Slate/950` → `--ds-color-slate-950`, `surface/accent` → `--ds-surface-accent`.

| Figma collection | Modes | CSS |
| --- | --- | --- |
| Primitives | Value | `:root` in `generated/primitives.css` |
| Spacing and Radius | Mode 1 | `:root` in `generated/spacing-and-radius.css` |
| Theme | Default, Indigo | one file per mode in `generated/themes/` |

Aliases are kept as `var()` references, so a theme token points at a primitive just like in Figma.
**Components use theme, spacing and radius tokens only, never primitives.**

## Themes

Each mode of the Theme collection is a theme. A theme applies to everything under an element
with `data-theme="<mode>"` (usually `<html>`). Default is also applied to `:root`.
Use the paintbrush in the toolbar to switch themes in any story.

## Updating tokens from Figma

1. Re-export the variables into `src/tokens/figma/variables.json` (same shape as today).
2. Run `npm run tokens` to regenerate `src/tokens/generated/`.
3. A new mode in the Theme collection becomes a new theme automatically, including in the toolbar.

Never edit files in `src/tokens/generated/` by hand.

## Adding a component

Create `src/components/<Name>/` with `<Name>.tsx`, `<Name>.css` and `<Name>.stories.tsx`,
then export it from `src/index.ts`.
